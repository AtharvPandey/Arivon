# Volume 1 — Chapter 7
## School Administrator Workspace & Dashboard

> This chapter defines the complete workspace of the School Administrator. The School Administrator is the highest authority within a school tenant and supervises all departments without performing their operational responsibilities.

# 1. Purpose

The School Administrator dashboard provides a 360° operational view of the institution.

Primary responsibilities:

- Monitor school operations
- Configure the ERP
- Manage users and permissions
- Review reports
- Track KPIs
- Approve configured workflows
- Communicate with stakeholders

The School Administrator is a supervisor, not an operator.

CAN:

# 6. Responsibilities

School Administrator CAN:

Administration
- Create users
- Disable users
- Reset passwords
- Manage departments
- Manage role templates
- Assign permissions

Academics
- View attendance
- View timetable
- View syllabus progress
- View student performance
- Notify teachers

Finance
- View fee status
- View income/expense summaries
- View outstanding dues
- Notify parents
- View vendor expenses

HR
- View employee directory
- View leave reports
- View payroll summaries
- View recruitment status

Admissions
- View applications
- Track admission pipeline
- View admission analytics

Communication
- Publish announcements
- Schedule circulars
- Send emergency alerts

Reporting
- Generate reports
- Export PDF/Excel
- View analytics
- Monitor audit logs

# 7. Restrictions

School Administrator CANNOT:

Attendance
- Mark attendance
- Modify locked attendance

Finance
- Collect fees
- Approve cash payments
- Edit transactions

Admissions
- Verify documents
- Complete admission workflow

Examination
- Enter marks
- Publish marks directly
- Evaluate papers

Library
- Issue books
- Return books

Transport
- Assign buses
- Modify routes

Hostel
- Allocate rooms

Operational ownership remains with the responsible department.

# 9. Audit & Monitoring

The dashboard exposes:

- Failed logins
- Recent permission changes
- User creation
- Deleted records
- Sensitive operations
- System alerts

# 10. Acceptance Criteria

The School Administrator must be able to understand the complete operational health of the school within five minutes of logging in, without entering individual modules.
